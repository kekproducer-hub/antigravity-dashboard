# Antigravity Practical Dashboard Assignment

Presentation dashboard for the AI training of administrative staff (Kyung Hee Cyber University).

- Type A: team assignments (executive overview dashboards, 9 teams in 4 offices)
- Type B: common assignment, RuleMate (AI regulation search tool)

## Files

- `index.html` : page structure
- `css/style.css` : styles (light/dark theme)
- `js/app.js` : data and rendering logic (includes the RuleMate prompt)

## Run

Open `index.html` in a browser. No build step. For GitHub Pages, publish the repository root (or this folder) from the main branch.
