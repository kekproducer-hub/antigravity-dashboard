실제성

가능한 범위에서 담당자가 실제 업무에서 다루는 데이터를 사용한다.

의사결정성

그래프 나열에 그치지 않고, 상사 또는 담당자가 무엇을 판단할 수 있는지 제시한다.

문제발견성

이상치·위험구간·증감폭·반복 패턴 등 문제 신호를 찾을 수 있도록 구성한다.

재사용성

보안성

개인정보·민감정보·내부 제한정보는 비식별화 또는 집계 수준으로 처리하며 외부 공개를 전제로 하지 않는다.

구현 목표

규정 PDF가 들어가서 근거 카드가 나온다

대학 규정 PDF를 활용해 자연어 질문의 맥락을 이해하고 정확한 조문을 근거로 답변하며, 기안문·품의문 초안을 넣으면 부합하는 근거 규정을 여러 개 추천합니다.

STEP 1규정 PDF 수집

프로젝트 폴더의 규정 PDF 전체를 자동 탐색하고, 파일명에서 규정명과 개정일을 추출합니다.

STEP 2구조화

텍스트와 표를 추출해 조·항·호·목·별표 단위로 나누고 페이지 번호를 보존합니다.

STEP 3의미 기반 검색

Gemini File Search 또는 임베딩 벡터 검색을 우선 활용하고, 최신 개정본을 우선합니다.

STEP 4근거 답변

AI 요약 답변과 근거 카드 3~5개를 보여주고 신뢰성 상태를 표시합니다.

데이터 처리 7원칙

입력 데이터를 다루는 방법

  1. 프로젝트 폴더의 모든 규정 PDF를 자동 탐색
  2. 텍스트와 표를 구조적으로 추출하고 페이지·파일명 보존
  3. 조·항·호·목·별표 등 작은 의미 단위로 분할
  4. 파일명에서 규정명·개정일을 메타데이터로 저장
  5. 동일 규정의 여러 개정본은 최신 개정일을 우선하되 구버전 존재도 표시
  6. 표 안의 승진점수·등급·금액·기간도 검색 대상에 포함
  7. 개인정보는 화면과 로그에 불필요하게 노출하지 않음

중요한 답변 원칙

  • 규정 PDF 원문을 최우선이자 유일한 근거로 사용한다.
  • 웹검색이나 모델의 일반지식으로 규정 내용을 보충하거나 만들어내지 않는다.
  • 근거를 찾지 못하면 “현재 등록된 규정에서 관련 근거를 확인하지 못했습니다.”라고 표시한다.
  • 충돌하거나 해석이 갈리면 하나로 확정하지 않고 각각의 근거를 보여준다.
  • 숫자·점수·기간·금액·직급 기준은 원문 표나 조문을 다시 확인해 그대로 제시한다.

두 가지 모드

  • A. 규정에 대해 질문하기
    큰 입력창에 자연어로 질문 → 의도를 파악해 관련 조항을 종합한 답변을 먼저 제시
  • B. 기안문에서 근거 찾기
    기안문·품의문 전체를 붙여넣기 → 목적·행위·대상·업무 맥락을 분석해 근거 후보 3~5개와 관련 이유를 제시
